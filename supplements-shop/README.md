# Supplements Shop (MVP)

A modern, mobile-friendly supplements shopping site demo.

## Features (MVP)
- Product list + search/filter/sort
- Product detail page
- Cart (qty update, remove, clear)
- Checkout form (no payment integration)
- Order success screen
- Local persistence via localStorage

## Dev
```bash
npm install
npm run dev
```

## Codespaces public dev server
```bash
npm run dev:public
```
Uses port `18889` by default (to avoid conflicts with other apps).
